# vextjs v0.3.26

Released: 2026-06-15

## Changes

- `vext create` now defaults to a full-stack React template with user frontend source under `src/frontend/**`, `public`, frontend config, React dependencies, and API routes under `/api/*`; API-only scaffolding remains available through `--template api --frontend none`.
- Add `config.frontend`, `vextjs/frontend`, `vextjs/style`, client contract generation, esbuild browser bundling, React SSR/hydration, `res.render()` / `res.renderError()` page rendering, nested layout/i18n registries, render payload cache reuse, JSCSS extraction, and scoped SPA fallback assets under `dist/client`.
- Upgrade `schema-dsl` to `2.0.11`.
- Upgrade `monsqlize` to `2.0.6`, keeping the built-in database plugin on the same schema-dsl release line.

## Fixed Compatibility

- Fixes `vext dev` applications whose route files register schema-dsl custom types after being compiled to CJS while vext's OpenAPI or validation pipeline resolves schema-dsl through ESM.
- This addresses startup warnings such as `[schema-dsl] Unknown type "admin-permission-api", falling back to string` when the application has already called `DslBuilder.registerType()`.

## Validation

- Dependency lockfile refresh and release preflight should run after `schema-dsl@2.0.11` and `monsqlize@2.0.6` are available from npm.
