# v0.3.22 - 2026-06-10

## Changed

- `vext dev` now keeps the default terminal output minimal: ready URL(s), total startup time, and soft reload status only.
- `vext start` now prints production-oriented ready output with start mode, listening URL(s), total startup time, and cluster worker totals when applicable.
- Human-readable startup summaries and per-event details now require `--startup-profile`; `--startup-profile-json <path>` writes JSON without printing summary/details unless combined with `--startup-profile`.
- The root README now links to the public documentation site at the top of the page.

## Fixed

- `--port-conflict next` skips unavailable Windows probe ports such as `EACCES` / `EINVAL` instead of failing before checking the next candidate.
- Startup log quieting no longer overwrites an `app.logger.setLevel()` change made by user code during bootstrap or `onReady`.
- Default `vext dev` suppresses successful typegen details such as service dependency info diagnostics while still showing warnings and errors.
