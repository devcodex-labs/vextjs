# v0.3.8 — 2026-05-31

## 概述

本版本聚焦发布前收口：将前序审计修复、外部消费者验证与 npm 包产物边界统一纳入发布基线。

---

## Changed

- 发布版本升级到 `0.3.8`，避开 npm registry 已存在的 `vextjs@0.3.7`。
- `npm run build` 现在会先清理 `dist/`，避免旧构建产物残留进入发布包。
- TypeScript 构建关闭 `sourceMap` 与 `declarationMap`，正式 npm 包不再携带当前无源码配套的 `.map` 文件。
- `prepublishOnly` 改为执行完整 `npm run build`，确保发布前走相同的清理与双产物构建路径。

---

## Fixed

- 收敛 adapter route-level body parser 与全局 body-size 限制语义。
- 收敛 multipart/raw body 读取边界，避免超过限制后仍继续无界读取。
- 收敛 cluster `memoryThreshold` 配置覆盖与启动验证。
- 同步 README、website、CHANGELOG 与版本检查脚本所需的发布版本口径。

---

## Validation

发布前验证要求：

- `bash scripts/check-version-sync.sh`
- `npm run lint`
- `npm run typecheck`
- `npm run build`
- `npm run test:unit`
- `npm run test:int`
- `npm run test:e2e`
- `npm run verify:exports`
- `npm run verify:adapters`
- `cd website && npm run build`
- `npm pack --dry-run`
- `cd ../vext-test && npm run verify:all`

---

## Notes

- 本版本不执行 `publish`、`tag` 或 `push`。真实发布动作仍需要单独确认。
