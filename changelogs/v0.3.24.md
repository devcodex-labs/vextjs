# v0.3.24 - 2026-06-11

## Added

- Added `logger.prettyColor: "auto" | "always" | "never"` for fixed ANSI colors on pretty level labels.

## Compatibility

- The new option only affects pretty text output. Production JSON logs remain uncolored, and no runtime color dependency was added.
- `FORCE_COLOR=1` enables auto color, `FORCE_COLOR=0`, `NO_COLOR`, `TERM=dumb`, or non-TTY output disables it unless `prettyColor: "always"` is configured.

## Verification

- Unit coverage: logger pretty color modes and config validation.
- Documentation: README and website logger/config/deployment/access-log guides.
