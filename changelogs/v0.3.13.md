# v0.3.13 - 2026-06-03

## Highlights

- 将路由级响应缓存运行时接入 `response-cache-kit@^1.1.0`，底层由 `cache-hub` 承接。
- 补齐响应缓存标签失效、指定 key 删除、统计、剩余 TTL、`partitionKey` 用户/租户隔离、`vary: "*"` 和 `allowAuthorizationCache` 能力。
- 通过 `response-cache-kit` single-flight 处理同 key 过期后的并发回源，避免缓存击穿。
- 将响应缓存文档从“路由缓存/缓存中间件”口径修正为用户视角的“响应缓存”配置，并明确 TTL 使用毫秒，HTTP `Cache-Control: max-age` 使用秒。
- 修正插件、服务、测试和 typegen 示例，避免把业务 Redis/测试缓存挂载到保留的 `app.cache` 控制面。
