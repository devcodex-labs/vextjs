# v0.3.23 - 2026-06-10

## Fixed

- Fixed `ColdRestarter.safeKill()` so Unix SIGKILL fallback checks actual process exit state instead of `child.killed`, which only means a signal was sent.
- Stabilized the SIGTERM-ignore unit fixture by registering signal handlers before emitting `ready`.
- Made the MonSQLize integration test MongoDB startup timeout configurable and raised the default to reduce first-download CI flakes.

## Verification

- Local CI: `npm run ci:local`
- Release surface: `npm run test:audit`, `npm pack --dry-run --json`, `npm publish --dry-run --access public`
- Consumer smoke: `vext-test` build, `verify:all`, and dev/start minimal/profile startup modes
