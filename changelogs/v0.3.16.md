# v0.3.16 - 2026-06-04

## Added

- Added `config.server` for inbound Node.js HTTP server settings: `requestTimeout`, `headersTimeout`, `keepAliveTimeout`, `socketTimeout`, `maxHeaderSize`, `maxRequestsPerSocket`, and `connectionsCheckingInterval`.
- Added shared runtime handling so production bootstrap, dev bootstrap, and built-in Native / Hono / Fastify / Express / Koa adapters consume the same server config contract.

## Compatibility

- `config.server` only affects inbound service requests and keeps omitted fields on the current Node.js / adapter defaults.
- Outbound `app.fetch` and `app.fetch.proxy` timeout behavior remains controlled by `config.fetch.timeout`, proxy target `timeout`, or per-call options.
- Third-party custom adapters remain source-compatible because the new `listen(..., options)` argument is optional; custom adapters must opt in to consume `options.server`.
- `keepAliveTimeoutBuffer` is intentionally not included because the current package baseline is Node.js `>=18.0.0`.

## Documentation

- Updated README, config guide, config API reference, Profile, and external consumer verification setup for `config.server`.
