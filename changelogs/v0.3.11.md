# v0.3.11 - 2026-06-01

## Changed

- Expand `vext create` output so new projects now include the documented convention directories for `src/locales/`, project-level `preload/`, and the TypeScript `src/types/generated/` typegen output path.
- Add scaffolded `src/config/local.example.*` and `src/config/bootstrap.example.*` files so users can discover the `local` and startup provider conventions without committing machine-local configuration.
- Update generated project README content so TypeScript and JavaScript scaffolds reference the correct config file extensions.
- Replace the root README with an English primary README covering setup, CLI usage, project structure, config, preload, routes, services, plugins, adapters, route cache, OpenAPI, i18n, and testing.
- Sync website quick-start, CLI, project-structure docs, and navigation version text with the new scaffold structure and `v0.3.11` release.
