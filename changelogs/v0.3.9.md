# v0.3.9 — 2026-06-01

## Changed

- Native adapter 路由注册与匹配核心从直接依赖 `find-my-way` 替换为 `route-core@^0.0.4`，保留用户路由 API、`req.params`、`req.route`、404/wrong-method 语义和 route-level options 行为。
- Raw Native benchmark 从 `http.createServer + find-my-way` 改为 `http.createServer + route-core`，并同步 README/website 的 Native 路由核心描述。
- benchmark 口径区分 `chain` handler 内联业务链与 `middleware-chain` 真实 route-level middleware chain，并在 benchmark 报告中说明 core-mode 与默认 runtime 性能边界。
- Native adapter 预计算 route-level bodyParser、去除 response requestId getter 闭包，并在 ALS 关闭路径减少 matched chain 执行闭包分配，以降低动态路由参数场景开销。
- release format gate 调整为变更文件 Prettier 门禁，保留 `format:check:all` 用于显式扫描历史全仓格式债务，避免 223 个历史格式问题阻断当前语义发布。
