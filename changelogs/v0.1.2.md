## ✅ 变更清单

### Bug 修复

#### BUG-001 (P0)：`vext dev` CJS/ESM 不兼容

**根因**：`DevCompiler`（开发编译器）将用户代码编译输出为 CJS 格式（`.vext/dev/*.js`），
但 `vextjs` 框架本身为纯 ESM（`"type": "module"`），CJS 产物通过 `require()` 加载时
命中 Node.js ERR_REQUIRE_ESM 错误，导致所有路由/服务无法加载。

**修复**：新增 `scripts/build-cjs.mjs` 脚本，使用 esbuild 将框架代码编译为 CJS 格式，
发布双包（ESM + CJS）。`package.json` exports 条件添加 `"require"` 入口。

**影响文件**：`package.json`、`scripts/build-cjs.mjs`（新建）

#### BUG-002 (P1)：文档 `app.decorate()` → `app.extend()`

**根因**：文档站 `guide/introduction.md` 中插件 API 示例使用了已废弃的
`app.decorate()` 方法名，实际 API 为 `app.extend()`。

**修复**：更新文档中所有 `app.decorate()` 引用为 `app.extend()`。

**影响文件**：`website/docs/guide/introduction.md`

### 功能增强

#### 双包发布（ESM + CJS）

**变更**：vextjs 现在同时提供 ESM 和 CJS 两种格式：

```
dist/
├── index.js          ← ESM（保持不变）
├── index.cjs         ← 🆕 CJS（新增）
├── testing/
│   ├── index.js      ← ESM
│   └── index.cjs     ← 🆕 CJS（新增）
```

`package.json` exports 字段：
```json
{
  ".": {
    "import": "./dist/index.js",
    "require": "./dist/index.cjs"
  },
  "./testing": {
    "import": "./dist/testing/index.js",
    "require": "./dist/testing/index.cjs"
  }
}
```

#### `VextPlugin` 生命周期钩子

**变更**：`VextPlugin` 接口新增可选生命周期钩子：

```typescript
interface VextPlugin {
  name: string;
  setup(app: VextApp): void | Promise<void>;
  onReady?(app: VextApp): void | Promise<void>;   // 🆕 服务启动就绪后触发
  onClose?(app: VextApp): void | Promise<void>;   // 🆕 优雅关闭时触发
}
```

框架在 `bootstrap` 完成后自动调用 `onReady`，在 `shutdown` 流程中自动调用 `onClose`，
无需手动注册。

### 类型增强

#### TYPE-001：`VextServices` 索引签名 `unknown` → `any`

**变更**：`VextServices` 接口索引签名从 `unknown` 改为 `any`：

```typescript
// 修复前 — 需要类型断言
(app.services.user as UserService).findAll()

// 修复后 — 直接调用
app.services.user.findAll()
```

允许用户直接调用 service 方法而无需频繁类型断言，符合实际使用场景。

#### TYPE-002：`app.throw()` 支持 `string` 业务码

**变更**：`app.throw()` 第三参数（业务错误码）现在同时支持 `number` 和 `string`：

```typescript
// 修复前 — 仅支持 number
app.throw(400, '参数错误', 10001)

// 修复后 — number 和 string 均支持
app.throw(400, '参数错误', 10001)        // number 业务码
app.throw(400, '参数错误', 'INVALID_INPUT')  // string 业务码（如枚举值）
```

`HttpError.code` 类型同步扩展为 `number | string`。

#### TYPE-003/004：`VextPlugin` 添加 `onReady` / `onClose`

（见上方「VextPlugin 生命周期钩子」章节）
