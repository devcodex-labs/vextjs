# v0.3.5 — 2026-05-15

## 文档口径收口：README × OpenTelemetry

### 概述

本版本聚焦文档一致性收口，不改动运行时代码。核心目标是把 `README.md` 与 `website/docs/examples/opentelemetry.md` 统一到当前 `vext.preload`、`package.json vext.otel`、运行期插件行为与 `capture` 声明式采集模型，避免用户仍按旧的 exporter / 状态字段 / 安装方式理解接入链路。

---

### Changed

- `README.md` 新增 preload 型生态能力说明，并补充 OpenTelemetry 零配置接入入口。
- README 快速开始新增 `vextjs-opentelemetry` 最小接入示例，明确 `vext start` / `vext dev` 会自动注入 preload 初始化。
- `website/docs/examples/opentelemetry.md` 补充 VextJS 场景下的配置读取优先级说明。
- `website/docs/examples/opentelemetry.md` 新增 `capture` 声明式采集章节与完整配置示例，覆盖 headers / query / params / body 的推荐用法与边界。

---

### Fixed

- 修正文档中旧的 `/_otel/status` 字段口径，统一使用 `exportMode` / `exportTarget` / `protocol` / `samplingRatio`。
- 修正文档中旧的安装/导出说明，明确 `vextjs-opentelemetry` 已内置常用 OTel SDK 依赖与 auto-instrumentation。
- 修正文档站与 README 的版本示例，统一同步到 `v0.3.5`。
- 刷新锁文件中的传递依赖解析结果，将 `fast-uri` 收口到 `3.1.2`，消除本轮发版前生产依赖审计中的高危项。
