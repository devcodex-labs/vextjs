 # v0.3.3 — 2026-05-06

## ts-morph 开发辅助能力二期收口

### 概述

本版本继续围绕 `ts-morph` 开发辅助能力推进第二阶段：在前一批 `route index + doctor routes + routes inspect/manifest` 的基础上，新增 `vext typegen --write-manifest`，正式输出 `.vext/inspect/services.manifest.json`，将 service 索引、`app.extend()` 聚合结果与服务依赖图摘要沉淀为稳定消费层。同时补齐 README / CLI / Services 文档与站点版本标识，形成面向 `0.3.3` 的可发布边界。

---

### Added

- 新增 `src/tooling/typegen/write-service-manifest.ts`，支持生成 `.vext/inspect/services.manifest.json`。
- 新增 `src/tooling/typegen/merge-app-extensions.ts`，统一 `app.extend()` 的聚合、冲突回退与置信度规则，供 generated d.ts 与 services manifest 共用。
- `vext typegen` 新增 `--write-manifest` 选项，可在生成声明的同时输出稳定消费层 manifest。
- 新增 `test/golden/typegen/ts-basic/services.manifest.json`，为 services manifest 引入 golden 基线。

---

### Changed

- `generate-app-extensions-dts.ts` 改为复用共享聚合逻辑，避免 generated 声明与 services manifest 漂移。
- README、CLI 文档、Services 文档统一补齐 `services.manifest.json` 的入口、边界与产物说明。
- 文档站导航版本标识更新为 `v0.3.3`。

---

### Documentation

- `README.md` 新增 `vext typegen --write-manifest` 示例，并补充 `services.manifest.json` 与 routes manifest 的分层说明。
- `website/docs/guide/cli.md` 新增 typegen manifest 选项、services/routes 双 manifest 的边界说明。
- `website/docs/guide/services.md` 补充 service manifest 的使用方式与产物路径。
