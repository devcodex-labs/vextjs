# v0.3.6 — 2026-05-17

## 概述

本版本承接已发布的 `v0.3.5` 文档收口，在此基础上正式交付一轮**项目级 preload 能力增强 + 发布验证闭环**：

1. 完成第 4、5 项遗留问题收口
   - `vext create` 成功提示中的文档入口改为 `https://vextjs.github.io`
   - benchmark 页面补充 Raw / Vext 的对比口径说明
2. 正式落地**项目级 `preload/` 目录**能力
   - 应用项目可直接使用项目根 `preload/`
   - 无需再先包装成本地 npm 包才能做启动前 preload
3. 首期支持 TS preload
   - `.mjs` / `.js` / `.ts` / `.mts`
   - 启动链路会先把 TS preload 编译到 `.vext/preload/*.mjs`
4. `vext build` 正式接管项目级 preload 产物
   - 自动编译到 `dist/preload/`
   - built 模式在项目根缺失 `preload/` 时可回退读取 `dist/preload/`
5. 完成主仓库门禁、`vext-test` 真实消费方验证与发布口径纠偏
   - 纠正“这批变更误写为 `0.3.5`”的问题
   - 本轮正式按 `0.3.6` 对外发布

## Added

- 新增**项目级 `preload/` 目录**支持：`vext start` / `vext dev` / Cluster 会在项目根自动扫描 `preload/`。
- 新增项目级 preload 文件类型支持：
  - `.mjs`
  - `.js`
  - `.ts`
  - `.mts`
- 新增 **TS preload 启动前编译**：
  - `preload/*.ts` / `preload/*.mts`
  - 会在启动前编译到 `.vext/preload/*.mjs`
  - 再统一通过 `--import` 注入
- 新增 `ColdRestarter#setExtraExecArgv()`，允许 dev 模式在 cold restart 前刷新 preload 注入参数。
- `vext-test` 新增真实消费方验证夹具：
  - `preload/01-bootstrap-port.ts`
  - `preload/02-bootstrap-verbose.mjs`
  - `verify-project-preload.mjs`

## Changed

- `resolvePreloads()` 从同步函数升级为统一的异步解析入口，同时负责：
  - 项目级 preload 发现
  - 包级 `vext.preload` 发现
  - 聚合顺序控制
  - 绝对路径去重
- `vext dev` 在首次启动、手动重启、cold restart 前都会刷新 preload 列表，确保项目级 preload 改动能真正生效。
- `VextFileWatcher` 现在会监听项目根 `preload/` 目录；相关变更统一归类为 **cold restart**。
- `vext build` 现在会自动将项目根 `preload/` 编译到 `dist/preload/`，并在再次构建时清理陈旧产物。
- built 模式下 `resolvePreloads()` 会在项目根没有 `preload/` 时回退读取 `dist/preload/`，降低只携带 `dist/` 部署时的摩擦。
- `fs.watch` 模式下，启动后动态创建/删除项目根 `preload/` 目录时，会自动补挂/释放 watcher，并对新增 preload 文件补发 cold 事件。
- 文档站与 README 已补齐以下说明：
  - 项目级 `preload/` 目录
  - TS preload 编译行为
  - `vext dev` 下 preload 变更会触发 cold restart
  - `vext build` / built 模式与 `dist/preload/` 的联动行为

## Fixed

- 修复“项目级 preload 仅存在于方案中、CLI 实际无法识别”的能力缺口。
- 修复“目录级 preload 若使用 TypeScript，`start` / Cluster 下缺少运行机制”的设计缺口。
- 修复“开发态修改 `preload/` 后不会自动生效”的开发体验缺口。
- 修复“构建产物只带 `dist/` 时项目级 preload 失效”的部署缺口。
- 修复 `vext create` 成功提示中的文档地址，已从 GitHub 仓库入口更新为 `https://vextjs.github.io`。
- 修复 benchmark 页面说明不足的问题，现已明确标注 Raw / Vext 对比口径及关闭的非核心默认能力。
- 修复 `vext-test` 中消费者验证脚本对固定端口的错误假设，确保真实监听端口变化时仍能稳定通过最终验收。
