# v0.3.18 - 2026-06-07

## Changed

- Raised the framework Node.js baseline to `>=20.19.0`.
- Moved `@koa/router` out of production `dependencies`; it is now an optional peer dependency and a repository development dependency.
- Replaced the `mongodb-memory-server` wrapper with `mongodb-memory-server-core@11.2.0` in test/dev paths to avoid install-time wrapper postinstall downloads and keep test binary downloads controlled.
- Updated CJS bundle externals so optional adapter dependencies and memory-server tooling are not bundled into the root CJS entry.

## Fixed

- Added cleanup for MonSQLize in-memory MongoDB instances across setup failure paths and app close hooks.
- Synced unit/integration tests, website docs, README, Profile, and `vext-test` external consumer baseline with the new dependency layout.

## Documentation

- Improved website discoverability and consistency for `app.throw` details, runtime hooks, response cache, and Apache-2.0 license wording.
