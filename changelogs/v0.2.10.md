## Changes Summary

Bug fix: dev mode sourcemap `sourceRoot` configuration removed.

In dev mode, esbuild-generated sourcemaps included an incorrect `sourceRoot` field pointing to the project's `src/` directory. This caused V8 to resolve source paths relative to `srcDir` instead of the output file location, resulting in stack traces that were missing one path segment (e.g., `/projects/src/services/blog.ts` instead of `/projects/admin/src/services/blog.ts`).

---

## Bug Fixes

### Dev Mode Stack Trace Path Missing Project Directory Segment

**Problem**:

Error stack traces in dev mode showed incorrect file paths — one directory segment was missing. For a project located at `/projects/admin/`, the stack trace would show:

```
TypeError: ...
    at handler (/projects/src/services/blog.ts:42:10)   ❌ missing "admin/"
```

**Root Cause**:

`DevCompiler` set `sourceRoot: this.srcDir` in the esbuild options for both `start()` and `rebuildWithNewEntryPoints()`. With `outbase: srcDir` and `sourcemap: true`, esbuild generates `sources[]` entries as relative paths from the output file location (e.g., `../../src/services/blog.ts`). V8 normally resolves these relative to the output file and gets the correct absolute path. Adding `sourceRoot: srcDir` (e.g., `/projects/admin/src`) changes the base: V8 resolves `../../src/services/blog.ts` relative to `/projects/admin/src`, yielding `/projects/src/services/blog.ts` — the `admin/` segment is lost.

**Fix**:

Removed `sourceRoot: this.srcDir,` from both `start()` and `rebuildWithNewEntryPoints()` in `src/lib/dev/compiler.ts`. The relative source paths generated by esbuild are already correct without `sourceRoot`.

**Files Changed**:

- `src/lib/dev/compiler.ts`: Removed `sourceRoot` from `start()` esbuild options and `rebuildWithNewEntryPoints()` esbuild options.

**Verification**:

After the fix, triggering a runtime error in vext-test produces stack traces with the full correct path:

```
TypeError: Cannot read properties of undefined (reading 'name')
    at Object.handler (E:\Worker\vext-test\src\routes\index.ts:374:16)   ✅ full path
```
