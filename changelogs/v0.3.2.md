# v0.3.2 — 2026-04-28

## 启动体验与远程配置优化

### 概述

本版本补齐启动期远程配置能力与启动体验治理：新增 `src/config/bootstrap.ts` 的 bootstrap config provider 契约，让数据库、密钥、基础设施配置可以在配置冻结与 MonSQLize / 插件初始化前完成注入；同时增加端口冲突策略、生命周期日志分层，并修复上轮验证发现的测试与 IPC 问题。

---

### Added

- 新增 `defineBootstrapConfig()` 与 `BootstrapConfigProvider`，支持在 `src/config/bootstrap.ts` 注册启动期配置 provider。
- 新增 `bootstrap provider patch` 合并层：`default < env < local < provider < CLI`。
- 新增 provider 超时、必需/可选策略：`production` 默认 fail-fast，`development/test` 默认 warning 后继续。
- 新增 Cluster 场景下 Master 解析 provider patch 后注入 Worker 的一致性链路，避免同一启动周期内 Master/Worker 配置分裂。
- 新增端口冲突策略：`error` / `prompt` / `kill` / `next`，并支持 `VEXT_PORT_CONFLICT`。
- 新增生命周期日志分层：`logger.lifecycleLevel = "concise" | "verbose"`，用于区分默认摘要日志与排障详细日志。
- 新增 ESLint flat config 与依赖，使 `npm run lint` 成为可执行验证链路。

---

### Fixed

- 修复 `soft-reloader` 测试断言与默认 `concise` 生命周期日志不一致的问题：详细阶段耗时断言改为显式启用 `verbose`。
- 修复 lifecycle IPC 在 Vitest worker 中误发送 `process.send({ type: "lifecycle-config" })` 的问题，仅允许 `VEXT_MODE=start/dev` 的框架子进程发送。
- 修复生产依赖审计中的 `picomatch` 高危项，`npm audit --omit=dev` 已为 0 vulnerabilities。
- 修复 Nacos 真实验证脚本硬编码真实地址/凭据的问题，改为环境变量注入并在缺参时安全跳过。
