# v0.3.1 — 2026-04-27

## Plugin Loader ESM-only 兼容修复

### 概述

修复 `vext dev` 下用户插件依赖 import-only ESM 包时的加载失败问题。典型场景是插件编译为 CJS 后执行 `require("vextjs-nacos")`，而依赖包只提供 `exports.import`、不提供 `exports.require`，导致 Node.js 抛出 `No "exports" main defined`。

---

### Fixed

- 修复 `plugin-loader` 的 ESM-only 预加载解析上下文：按插件编译产物所在项目创建 resolver，而不是使用框架自身的 `createRequire(import.meta.url)`。
- 支持 strict exports 包结构：在 `package.json` 不导出 `./package.json` 时，通过插件项目的 `node_modules` 搜索路径定位真实包目录。
- 支持 import-only 根包：解析 `exports["."].import` 并通过绝对 `file://` 路径预加载。
- 支持 import-only 子路径：解析 `exports["./subpath"].import`，并按完整 request（如 `esm-only-pkg/subpath`）缓存，确保 CJS `require()` 能命中预加载模块。
- 修复 CJS bundle 中 `createRequire(import.meta.url)` 的运行时兼容：构建脚本为 CJS 输出注入 `import.meta.url` 等价值。
