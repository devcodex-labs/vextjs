# v0.3.17 - 2026-06-05

## Added

- Added JSON-safe `details` support to `HttpError` / `app.throw`, including object-style `app.throw({ status, message, code, details })` and fourth-argument details shortcut for `app.throw(status, message, params, details)`.
- Added `app.hooks.on(name, handler)` with request/route, validation, handler, response, error, fetch/proxy, service, cache, plugin, routes, OpenAPI, server, ready, and close lifecycle hooks.
- Added `details` to the generated OpenAPI `ErrorResponse` schema.

## Compatibility

- Existing `app.throw(status, message, code)` and `app.throw(status, message, params, code)` calls remain compatible. Fourth argument `number` / `string` remains business `code`; fourth argument object / array is treated as `details`.
- Unknown runtime `Error` objects still do not expose arbitrary details. Details are only returned when supplied through `HttpError` / `app.throw`.
- `OpenAPIGenerator.generate()` remains synchronous. OpenAPI hooks are emitted from bootstrap / dev bootstrap / route reload generation paths.
- `VextApp.hooks` exposes only public registration helpers (`on` / `has`) while internal lifecycle emission stays inside the runtime.
