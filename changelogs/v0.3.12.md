# v0.3.12 - 2026-06-02

## Changed

- OpenAPI schema generation now supports field-level business descriptions from schema-dsl builders, including `"string:1-20000!".description("...")` and `dsl("string!").description("...")`.
- Preserve field descriptions across request bodies, response schemas, nested objects, and object arrays while keeping `required`, `enum`, length, and numeric constraints intact.
- Add public `VextSchemaField` typing and `String.description()` type augmentation so route files can use the schema-dsl String extension through `vextjs` types.
- Document field-level OpenAPI descriptions in the validation guide, OpenAPI guide, and route definition API reference.
