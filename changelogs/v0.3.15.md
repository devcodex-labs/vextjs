# v0.3.15 - 2026-06-04

## Added

- Added root `app.fetch.proxy` for config-driven upstream request proxying.
- Added `config.fetch.proxy[]` target registration with `name`, `baseURL`, `headers`, `forwardHeaders`, `defaultInjectHeaders`, `allowAuthorizationForward`, `timeout`, `retry`, and `retryDelay`.
- Added public proxy-related types: `VextFetchClient`, `VextFetchConfig`, `VextFetchProxy`, `VextFetchProxyOptions`, and `VextFetchProxyTargetConfig`.

## Changed

- `app.fetch.create()` now returns a pure `VextFetchClient` without `.proxy`; proxying is only available on the root `app.fetch.proxy`.
- Upstream proxy responses are passed through directly for 2xx / 3xx / 4xx / 5xx instead of being wrapped by the normal response envelope.
- License metadata updated from MIT to Apache-2.0.
- Root package metadata, lockfile metadata, README license section, and package LICENSE text now use Apache-2.0.

## Documentation

- Updated fetch API, fetch guide, config reference, README, and external consumer validation notes for `app.fetch.proxy`.
