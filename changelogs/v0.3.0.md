# v0.3.0 — 2026-04-26

## MonSQLize 链式访问 API

### 概述

支持通过 `app.db.pool(name)` 和 `app.db.use(dbName)` 对多连接池和多数据库进行链式访问，对齐 monSQLize v1.3.0 新增的 `pool()` / `use()` 方法。同时新增 `VextModelDefinition.key` 别名字段，支持跨连接池短名注册。

---

### ⚠️ Breaking Changes

#### B1：`app.db.db()` 已移除

旧用法（无效）：
```ts
// 0.2.x — 实际是运行时 bug，monsqlize.db() 不存在
const db = app.db.db("admin");
```

新用法：改用 `use()` 或 `pool().use()`：
```ts
// 切换数据库（默认连接池）
const billing = app.db.use("billing");

// 多连接池 + 切换数据库
const cnBilling = app.db.pool("cn").use("billing");
```

#### B2：`app.db.use()` 变为单参数

旧用法：`use(connName, dbName)`  
新用法：`use(dbName)`（单库切换）；多连接池时用 `pool(poolName).use(dbName)`

---

### 新增功能

#### `app.db.use(dbName)` — 切换数据库（默认连接池）

```ts
// 等价于 msq.use('billing')，但 model key 自动带前缀
app.db.use('billing').collection('invoices')
app.db.use('billing').model('Invoice')  // 内部 key: BillingInvoice
```

#### `app.db.pool(poolName)` — 切换连接池

```ts
// 连接池访问器
const cn = app.db.pool('cn')

cn.collection('orders')                 // cn 池，默认库
cn.model('Order')                       // cn 池，默认库（key 原样）
cn.use('billing').collection('invoices') // cn 池，billing 库
cn.use('billing').model('Invoice')       // cn 池，billing 库（key: BillingInvoice）
```

#### `VextModelDefinition.key` — Model 别名

```ts
// model 文件
export default {
  name: 'BillingInvoice',   // 集合名（全路径）
  key: 'Invoice',            // 别名（跨池快捷 key）
  schema: { ... }
}

// 两个 key 均可获取
app.db.model('BillingInvoice')  // 按集合名
app.db.model('Invoice')          // 按别名（R5 双注册）
```

### 内部实现

| 模块 | 变更 |
|------|------|
| `connection.ts` | 移除 `db()`；新增 `use(dbName)` 含前缀逻辑；新增 `pool(poolName)` 完整访问器；`pool().use().model()` 双键回落（depth-2 优先 → depth-1 兜底）|
| `types.ts` | 新增 `PoolAccessor` 接口；更新 `MonSQLizeConnection`；新增 `VextModelDefinition`；新增 `useMemoryServer` / `memoryServerOptions` pool 字段 |
| `model-loader.ts` | R5 双注册：collectionName + def.key（含去重守卫）；depth-2 目录路由（`pool/db/model.ts` → 注册键 `PoolDbModel`）|
| `plugin.ts` | pool 配置展平（vext wrapper → monSQLize 扁平格式）；`useMemoryServer` 预处理（深拷贝绕过 freeze）；onClose 清理 memory-server |

---

#### Depth-2 目录路由（新增）

Model 文件放到 `models/<pool>/<db>/name.ts` 时，vext 自动注入连接池 + 数据库，并以 `PoolDbName` 作为注册键：

```
models/cn/billing/order.ts  →  CnBillingOrder
                               connection: { pool: 'cn', database: 'billing' }
```

`pool().use().model()` 链式访问时自动匹配：

```ts
// 等价两种写法
app.db.model('CnBillingOrder')           // 完整键
app.db.pool('cn').use('billing').model('Order')  // 短链（depth-2 key 优先，depth-1 兜底）
```

---

### 依赖更新

要求 monSQLize **>= 1.3.0**（`scopedCollection` / `scopedModel` / `pool` / `use` 方法）。

### 向后兼容性

| API | 状态 |
|-----|------|
| `app.db.collection()` | ✅ 不变 |
| `app.db.model()` | ✅ 不变（新增别名 key 支持）|
| `app.db.client` | ✅ 不变 |
| `app.db.use(db).model()` | ✅ 不变（key 仍为 `Db+Name`）|
| `app.db.pool().model(fullKey)` | ✅ 不变（传完整 key 仍生效）|
| `app.db.db()` | ❌ 已移除（B1）|
| `app.db.use(conn, db)` 双参 | ❌ 已移除（B2）|
