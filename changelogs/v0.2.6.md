## CI/CD

### CI-01: GitHub Actions 工作流

新增 4 个 GitHub Actions 工作流，覆盖从代码质量到发版的完整自动化：

| 工作流 | 文件 | 说明 |
|--------|------|------|
| CI | `.github/workflows/ci.yml` | Push/PR 触发，Node 18/20/22 矩阵，9 阶段质量门禁 |
| Docs | `.github/workflows/docs.yml` | main 分支推送时自动构建并部署文档站到 GitHub Pages |
| Release | `.github/workflows/release.yml` | Tag 推送时自动发布到 NPM + 创建 GitHub Release |
| Schema-DSL Compat | `.github/workflows/schema-dsl-compat.yml` | 定时检查 schema-dsl 新版本兼容性 |

CI 流水线阶段：

```
Lint → Typecheck → Build → Unit Tests → Integration Tests → E2E Tests → Coverage → Prettier Check → Version Sync → Docs Build
```

## Documentation

### DOCS-01: OpenTelemetry 文档全面重写

`website/docs/examples/opentelemetry.md` 全面重写精简：

- **SDK 初始化**：`initOtel` 改用 `vextjs-opentelemetry/koa` 子路径，统一 CJS `--require` 预加载模式
- **端点格式说明**：新增 gRPC h2c / OTLP HTTP / none 三种格式对照表
- **Egg.js 接入**：新增 `createEggMiddleware` 专属中间件，内置 trace_id / span_name / endpoint / latency_ms 自动注入 + `onCtxInit` / `onRequestDone` 回调
- **多框架示例精简**：Express / Koa / Hono / Fastify 示例统一精简，移除冗余 `withSpan` 样板代码
- **`getOtelStatus()`**：改为无参调用，自动读取环境变量
- **Runtime 指标**：新增 `@opentelemetry/instrumentation-runtime-node` 指标说明（CPU / 内存 / 事件循环 / GC）
- **框架差异对比表**：新增 VextJS / Egg.js / 其他框架的能力对比

### DOCS-02: `app.setLogger()` 文档扩展

- `website/docs/api/app.md`：新增 `app.setLogger(wrapper)` API Reference，含函数签名、OTel Logger Bridge 示例
- `website/docs/guide/logger.md`：新增「扩展 Logger：setLogger()」章节，含 Sentry 转发示例、child logger 注意事项
