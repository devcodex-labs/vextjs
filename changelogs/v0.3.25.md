# v0.3.25 - 2026-06-13

## Changed

- Normalized partial logger wrappers installed through `app.setLogger()`, preserving fallback methods, child loggers and runtime level control when plugins override only selected log methods.
- Upgraded direct runtime dependencies to the release-chain latest set:
  - `schema-dsl@2.0.10`
  - `monsqlize@2.0.5`
  - `esbuild@0.28.1`
  - `flex-rate-limit@2.2.4`
  - `response-cache-kit@1.2.1`
  - `route-core@0.0.7`
  - `fast-glob@3.3.3`
- Moved the optional benchmark runner to on-demand `npm exec --package=autocannon@8.0.0`, keeping `autocannon` and its transitive dependency tree out of the root install, audit and file-link consumer surface.

## Documentation

- Redesigned the Rspress documentation site theme, homepage, navigation, favicon and public logo assets around the Vext runtime-console visual direction.
- Refocused the documentation homepage on Native performance, three-tier server hot reload, ecosystem links, footer navigation and dark-theme readability.
- Hardened documentation homepage links, code block/callout contrast, reduced-motion behavior, ecosystem switcher layout and console playback visibility.
- Updated documentation version references to `0.3.25`.

## Compatibility

- SemVer: patch release.
- Breaking changes: none.
- Existing schema/OpenAPI validation, MonSQLize plugin contracts and adapter exports remain compatible.
- Consumers can upgrade without source changes when their Node.js runtime satisfies the existing `>=20.19.0` engine baseline.
