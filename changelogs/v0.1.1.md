## ✅ 变更清单

### 新增功能

#### `vext create` 交互式脚手架（Phase 4.2）

新增 `vext create <project-name>` CLI 命令，交互式创建 vextjs 项目：

**支持选项**：
- `--adapter hono|fastify|express|koa|native`：选择底层适配器（默认 `hono`）
- `--js`：生成 JavaScript 项目（默认 TypeScript）
- `--skip-install`：跳过 `npm install`
- `--force`：强制覆盖已存在目录
- `--template api`：项目模板类型

**生成文件清单**：
```
<project>/
├── package.json          ← 含 adapter 对应依赖 + type:module
├── tsconfig.json         ← TS 项目专用
├── .gitignore
├── README.md
├── src/
│   ├── config/
│   │   ├── default.ts     ← 基础配置
│   │   ├── development.ts ← 开发环境覆盖
│   │   └── production.ts  ← 生产环境覆盖
│   ├── routes/
│   │   └── index.ts       ← 示例路由
│   ├── services/
│   │   └── example.ts     ← 示例服务
│   └── types/
│       └── services.d.ts  ← TS 类型声明（TS 项目专用）
```

**测试覆盖**：95 个单元测试（参数解析、目录结构、模板内容、adapter 选项等）
